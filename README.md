# Fetch Pick and Place - Reinforcement Learning

A robotic manipulation project solving the continuous control `FetchPickAndPlace` environment using Gymnasium-Robotics and MuJoCo.

## 🚀 Features
- **Robotic Arm Manipulation:** Learns to reach, grasp, and place objects accurately in 3D space.
- **Custom GUI Dashboard:** Interactive user interface for hyperparameter tuning, training visualization, and evaluation.
- **Logic & Unit Tests:** Built-in verification with test suites (`test_fetch_pick_and_place_logic.py`).
